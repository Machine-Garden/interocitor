Boundary

The relay carries ciphertext. It is not blind to everything.

Cannot read

Encrypted row contents, file bodies, snapshots, and change payloads without the key.

Can still observe

Operational metadata such as sizes, timing, object names, device activity, and routing data.

Still your job

Device security, key recovery, auth policy, and product-specific threat modeling.

        Local data boundary

        Interocitor is the data layer, not a hosted service.

        Each TodoMVC client owns an independent MemoryLocalStore. A shared in-page filesystem carries their artifacts so you can inspect the exact files while the clients converge. A real application chooses persistence, encryption, and remote transport only when its product needs them.

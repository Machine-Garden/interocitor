interocitor examples

Run yarn demo:todo, then choose the flow you want to explore.

  • Live in-memory TodoMVC — up to three clients, inspectable mailbox files, compaction, and a live endpoint diff journal.
  • Live encrypted chat — two clients exchange protected messages and enforce an application-owned history limit.
  • Live shared board — independent local card edits converge after an explicit sync.
  • Protected family locator — encrypted location rows, freshness and safety boundaries, and endpoint-local change observation.
  • TODO app over local WebDAV — open it in two tabs to create and join an encrypted row-sync session.
  • Browser key custody: local storage + platform/cross-platform WebAuthn preferences — open it once to compare the application's three key-custody labels.
  • TODO app over Cloudflare — run an application-owned Worker using D1, R2, and optional realtime invalidation.

The Cloudflare example requires its linked Worker provisioning and local-run instructions.
